# XGBoost Home Price Prediction

This project predicts home prices using the XGBoost machine learning algorithm based on factors such as income, schools, hospitals, crime rates, and other housing-related features.

## Technologies Used

* Python
* Pandas
* XGBoost
* Jupyter Notebook

## Project Features

* Data preprocessing and cleaning
* House price prediction using XGBoost
* Model training and evaluation
* Data analysis using Pandas

## Files Included

* `housesales.ipynb` – Main notebook containing the code
* `kc_house_data.csv` – Dataset used for training and prediction
* `README.md` – Project documentation

## How to Run

1. Install required libraries
2. Open the notebook in Jupyter Notebook or Google Colab
3. Run all cells to train the model and generate predictions
